# GDB — Gold Daily Breakout system (XAUUSD CFD): backtest report

Costs: spread 0.35 USD/oz + slippage 0.10 USD/oz per fill; swap long -4%/yr, triple on Wednesday.
Parameters chosen on 2006-2014 only; 2015-2020 is untouched out-of-sample.
